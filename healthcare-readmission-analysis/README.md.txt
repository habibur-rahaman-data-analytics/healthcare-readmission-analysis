# Healthcare Readmission Analysis

## Project Overview
Analysis of hospital readmission patterns using the Diabetes 130-US Hospitals dataset.

## Business Questions
- What is the 30-day readmission rate?
- Which patient and encounter characteristics are associated with readmission?
- What patterns can help guide further investigation?

## Tools
Python, Pandas, SQL, Power BI

## Workflow
1. Data cleaning
2. Exploratory data analysis
3. KPI calculation
4. Pattern analysis
5. Dashboard development
6. Findings and recommendations

## Results
Add validated findings after completing the analysis.

## Dataset
Diabetes 130-US Hospitals, 1999–2008. See the dataset source and usage terms before redistributing data.
